# Caption fonts

Used for the word-by-word (reels) burned-in captions.

- **Noto Sans <script> Bold** (Telugu, Kannada, Devanagari, Tamil, Malayalam, Bengali, Gujarati, Gurmukhi, Oriya,
  Arabic, Ol Chiki) from https://github.com/notofonts/notofonts.github.io - SIL Open Font License 1.1.
- **Nunito Black** (English) - a static instance (weight 900) made from the variable Nunito font,
  https://github.com/googlefonts/nunito - SIL Open Font License 1.1.
